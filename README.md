# 02 React Cafe

A simple feedback application built with React and TypeScript.

Users can rate the café service by choosing one of three options:

- Good
- Neutral
- Bad

The app displays the total number of votes and the percentage of positive feedback.

## Technologies

- React
- TypeScript
- Vite
- CSS Modules
